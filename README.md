# MHWs スキルシミュ

**公開ページ: https://ibaran1um.github.io/mhw-sim/**

モンスターハンターワイルズのスキルシミュレータ。ブラウザだけで動く静的サイトです（サーバー不要）。

## できること
- 発動スキル（武器/防具/シリーズ/グループ）を指定して装備を検索（防御力順、最大30件）
- 追加スキル検索（各スキルを最大何Lvまで積めるか）
- 発動させたいスキルの下に攻撃力・会心率・属性値・会心倍率の目安を表示（常時／条件つきスキルがすべて発動した最大）
- 所持護石の登録、製作護石の利用、防具の固定・除外、装飾品の除外・所持数制限、防御力・耐性の下限
- **巨戟アーティア**：シリーズ・グループを「未定」にすると成立する組み合わせを自動で選ぶ。「切替チェック」で、どのシリーズ/グループなら成立するかを一覧表示
- **あれば成立する護石**：光るおまもりの抽選テーブル（レア5〜8）を当てはめ、どの護石が出れば成立するかを入手しやすい順に提案

## 仕組み
- `docs/solver.js` 0-1整数計画として定式化し、HiGHS（WASM）で解く
  - 防具は部位ごとに1つ（「なし」を含む）、装飾品は整数個
  - スロット制約は「Lv L 以上の装飾品数 ≤ Lv L 以上のスロット数」（L=1,2,3）を武器/防具で別々に課す
  - シリーズ/グループは各防具の部位カウントの合計、巨戟の付与分は既定で1部位
  - 鑑定護石はテーブルの行×各枠のスキル×スロットパターンを0-1変数にし、同じスキルの重複を禁止
  - 検索前に、関連スキル・スロット・防御力がすべて劣る防具を除外して問題を小さくする
- `docs/worker.js` 計算をWeb Workerで実行
- `docs/talisman_table.js` 鑑定護石の抽選テーブル
- `tools/build_data.py` ゲームデータ → `docs/data.json` 変換

## 既知の制限
- 限界突破は「レア5は3段・レア6は2段（タマミツネは1段）、左のスロットから1段ずつ、上限③」として計算（攻略Wikiの仕様に基づく）。防御力は強化上限がR5+8段・R6+6段・R7+5段・R8+4段（1段+2）上がるとして計算
- 巨戟アーティアの付与候補は全シリーズ/全グループを仮定（画面で候補から外せる）
- 鑑定護石テーブルは攻略Wiki掲載の内容に基づく
